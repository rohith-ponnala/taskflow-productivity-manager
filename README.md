# TaskFlow - Personal Productivity Manager

TaskFlow is a full-stack MERN productivity management application designed to help users organize tasks, track progress, and improve productivity.

## Features

- User Authentication (JWT)
- Task Creation and Management
- Task Priorities
- Smart Calendar View
- Productivity Statistics
- Task Search
- Browser Notifications
- Responsive UI

## Tech Stack

Frontend:
- React
- Vite
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication
